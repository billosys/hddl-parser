## What Worked

- Keeping the corpus policy in one existing matrix job made the Linux/macOS
  guarantee mechanical: qualifying events run the same named full-corpus step
  on both runner labels.
- The full-corpus condition is expressed only in terms of event name and
  default-branch refs, so branch pushes can remain broad without accidentally
  running the 900-case gate on every feature branch.
- Capturing the local full-corpus output to `/private/tmp` preserved the final
  command summary while keeping the interactive transcript readable.
