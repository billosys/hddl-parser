## What Worked

Running the aggregate ignored test command first showed that Cargo stops at the
first ignored unit-test failure, so the per-test exact probes were necessary
evidence rather than redundant detail.

Separating fast failure probes from bounded corpus probes made the route matrix
clear: three ignored tests need repair decisions, while two need an explicit
slow/corpus policy.
